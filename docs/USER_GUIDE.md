# Visto 用户手册

## 首次使用

首次打开 Visto 后，按照向导创建工作空间和 Owner 账号。

### 添加存储位置

创建项目之前需要至少一个可用存储位置。在 Owner 设置中进入存储管理，根据页面提示添加或选择存储位置。

### 创建项目

进入项目列表，选择“新建项目”，填写项目名称并选择存储位置。

## 上传与整理素材

进入项目后上传图片或视频。上传完成后，Visto 会创建媒体记录，并在媒体处理能力可用时生成预览或衍生版本。

## 审阅

打开素材进入审阅界面后，可以：

- 播放视频或查看图片
- 在时间点或画面上发表评论
- 添加评论附件
- 查看版本与审阅状态

## 分享

项目成员可以根据权限创建外部审阅链接。创建分享时请根据需要设置密码、有效期和访问范围。

## 成员与权限

Owner 和项目管理者可以管理成员及项目权限。只给用户完成工作所需要的权限，不要共享 Owner 账号。

## 存储与删除

删除、迁移或调整存储前先确认受影响的项目和素材。重要项目建议在大规模调整前先完成备份。
