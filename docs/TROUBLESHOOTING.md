# 故障排查

## 页面打不开

先确认服务是否仍在监听默认地址：

```bash
curl -i http://127.0.0.1:8787/health/ready
```

如果安装时使用了自定义端口，请替换上面的端口。

## 视频无法预览

检查 `/health/ready` 返回的 FFmpeg/ffprobe 状态。原生 Server 主包不直接捆绑 FFmpeg；媒体运行时未安装或不可用时，视频预览和转码功能会受影响。

## 更新失败

不要删除数据目录。保留报错信息、当前版本和备份文件，再检查更新包与签名元数据是否来自同一正式 Release。

## 恢复被拒绝

先运行恢复脚本的 `--check-only`。如果工具拒绝恢复，说明它无法证明该备份能够安全写回当前实例；不要通过手工解压覆盖数据来绕过保护。

## 报告问题时

请提供：

- Visto 版本
- macOS 版本
- 问题发生时间
- 可复现步骤
- 已脱敏的错误信息

不要公开发送数据库、媒体原文件、访问令牌、存储密码、私钥或包含真实凭据的配置文件。
