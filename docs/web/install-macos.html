macOS 安装

适用于 Apple Silicon（M 系列）Mac。Intel Mac 暂不在支持范围内。准备管理员密码并保持联网，下载开放情况见下载页。

方式一：在线安装（推荐）

打开“终端”，复制这一行并回车：

curl -fsSL https://visto.akahxh.top/install.sh -o install-visto.sh && bash install-visto.sh

脚本先以当前用户检查 macOS 是否允许程序运行，再请求管理员密码安装。按提示确认视频组件下载。密码输入时不显示字符，这是正常现象。脚本会自动选择最新正式版，下载、检查并安装 Server 和视频组件；无需填写版本或组件名称。

安装结束后，打开终端显示的地址，按首次设置创建工作空间。默认是 http://127.0.0.1:8787/；如果端口已被占用，安装器会询问是否使用其他空闲端口。

方式二：手动下载后安装

  1. 在下载页或 GitHub Releases 取得 macOS · Apple Silicon 程序包。
  2. 双击压缩包解压，保留原文件夹名称，例如 Visto-Server_1.0.3_macos-arm64，不要与旧版本混在一起。
  3. 在 Finder 中右键点击解压后的文件夹，选择“服务 → 新建位于文件夹位置的终端窗口”。

先取得安装辅助脚本：

curl -fsSL https://visto.akahxh.top/install.sh -o install-visto.sh

再安装这个文件夹里的版本：

bash install-visto.sh --source-dir .

它使用已经解压的程序，不再下载或切换到其他 Server 版本；视频组件由脚本自动准备。原始 1.0.3 包也使用这两条命令，无需给旧安装器添加新参数。

完成后打开终端显示的地址。两种方式都已包含视频组件安装，不需要额外执行一段组件安装命令。

如果 macOS 提示无法打开

当前程序没有 Apple 开发者签名与公证。脚本会在安装前检查 visto-server 与 visto-core 是否能运行，不会替你关闭系统安全检查。

  1. 弹窗出现时点击“完成”，不要将程序移到废纸篓。
  2. 脚本会尝试打开系统设置 → 隐私与安全性；没有打开时，手动进入该页面。向下滚动到“安全性”，点击终端提示的那个程序的“仍要打开”。如果再次出现确认弹窗，点击“打开”或“允许”。
  3. 保留终端窗口。完成放行后，回到终端按回车，安装就会继续。 无需复制另一条命令，脚本会重新检查同一份程序。

两个程序可能需要分别放行；按终端提示依次处理即可。此时系统服务还没有开始安装。若没有“仍要打开”按钮，关闭并重新打开“隐私与安全性”；仍没有入口时，将终端错误提供给维护者。

想稍后安装时，在等待提示处输入 q 或按 Control-C。脚本会保留安装文件，并显示一条下次继续的命令；只有暂停或退出后才需要使用它。不要重复最初的在线下载命令，它会创建另一份安装文件。完成放行后，脚本才会请求管理员密码并继续安装。

安装之后

上传一个短视频，确认预览可以播放，再开始正式项目。服务管理、日志和卸载见更新与维护。
