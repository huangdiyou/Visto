安装 Visto

团队已经部署 Visto 时，在浏览器打开工作空间地址即可。自己建立工作空间时，可以选择两种方式：

  • 在线安装（推荐）：复制一条命令，自动获取对应系统的最新正式版，完成程序和视频组件安装。
  • 手动安装：自行从 GitHub 下载程序包，再按系统指南分步执行命令。适合希望自行选择版本或已经下载好安装包的用户。
设备 安装指南 说明
M 系列 Mac macOS 安装 Apple Silicon；需要管理员密码
Windows 电脑 Windows 安装 x64；需要管理员权限
Linux 服务器 Linux 安装 x86_64 / ARM64，使用 systemd
已经使用 Docker Docker 部署 适合熟悉容器的用户

下载是否开放见下载页。官网安装脚本独立于程序包提供，原始 1.0.3 包也可使用；不需要为了取得安装辅助工具重新下载新版程序。手动方式安装你下载的版本，在线方式每次获取最新正式版。

安装前准备

  • 留出存放原片、预览和备份的磁盘空间。
  • 为媒体选择独立文件夹，不要选择整个主目录或系统目录。
  • 已有 Visto 实例时先看更新与维护，不要重新安装覆盖现有数据。

安装完成后

打开安装终端显示的地址，按首次设置创建账号和工作空间。默认地址是 http://127.0.0.1:8787/；端口变更时以终端提示为准。Docker 默认使用 http://127.0.0.1:8080/。

这里的 127.0.0.1 表示当前设备。给同事或客户使用时，请配置团队访问地址。
