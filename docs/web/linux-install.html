Linux 安装

适用于 x86_64 / ARM64 的 systemd Linux 服务器。要求内核 4.18+、glibc 2.28+、systemd 239+，以及 sudo 权限、Bash、GNU tar 和 curl。下载开放情况见下载页。

方式一：在线安装（推荐）

在服务器终端复制这一行：

curl -fsSL https://visto.akahxh.top/install.sh -o install-visto.sh && sudo bash install-visto.sh

脚本会识别架构、获取最新正式版并安装程序和视频组件。按终端提示确认下载，等待完成；无需选择组件或填写版本号。

方式二：手动下载后安装

  1. 从下载页或 GitHub Releases 下载对应架构的 Linux 包。普通 Intel / AMD 服务器选 x86_64，ARM 服务器选 ARM64。
  2. 保留压缩包原名，把它放到独立安装文件夹；这个文件夹内只保留一个 Visto .tar.gz 包。
  3. 在该文件夹打开终端，取得辅助脚本：
curl -fsSL https://visto.akahxh.top/install.sh -o install-visto.sh

安装这个已经下载的包：

sudo bash install-visto.sh --package ./Visto-Server_*.tar.gz

脚本会自动解压，使用包名中的版本，并准备视频组件；不会替换成其他 Server 版本。无需手动比对校验值。

打开工作空间

使用安装终端最后显示的地址；默认是 http://127.0.0.1:8787/。有浏览器的服务器可直接按首次设置创建工作空间。

远程服务器可通过 SSH 临时打开设置页面。在自己的电脑终端执行，把 user@server 换成实际 SSH 登录地址：

ssh -N -L 18787:127.0.0.1:8787 user@server

保持 SSH 连接，在自己的浏览器打开 http://127.0.0.1:18787/。如果安装端口变更，也要调整转发命令中的服务器端口。日常协作使用团队访问地址。

服务管理、日志、备份和卸载见更新与维护。
