Install Visto

If your team already runs Visto, open its workspace address in your browser. To host your own workspace, choose either route:

  • Online installation (recommended): one command obtains the latest stable release for your system and installs Server with video support.
  • Manual installation: download a package from GitHub, then follow the commands for your system. Use this when you want a particular version or already have the package.
Device Guide Requirements
M-series Mac macOS Apple Silicon; administrator password
Windows PC Windows x64; administrator privileges
Linux server Linux x86_64 / ARM64; systemd
Existing Docker setup Docker Familiarity with containers

See downloads for availability. The website installer is delivered separately and also works with the original 1.0.3 package. Online installation resolves the latest stable release on each run; manual installation uses your downloaded version.

Before installing

  • Leave enough disk space for originals, previews, and backups.
  • Choose a dedicated media folder rather than your entire home or a system directory.
  • For an existing instance, read maintenance first.

After installation

Open the address printed by the installer and follow first setup. The default is http://127.0.0.1:8787/; use the printed address if the port changes. Docker defaults to http://127.0.0.1:8080/.

127.0.0.1 refers to the device running the browser. Configure a team address for other people.
