Windows 安装

适用于 Windows x64。需要管理员权限。以下步骤用于原生 Server；项目成员使用浏览器即可。

方式一：在线安装

在开始菜单搜索 Windows PowerShell，选择“以管理员身份运行”。复制这一行并回车：

Invoke-WebRequest -UseBasicParsing https://visto.akahxh.top/install.ps1 -OutFile install-visto.ps1 -ErrorAction Stop; powershell -NoProfile -ExecutionPolicy Bypass -File .\install-visto.ps1

脚本会获取最新正式版，自动检查安装包并安装至 C:\Program Files\Visto Server。按提示确认，等待服务和视频组件就绪。Windows 包自带视频组件，无需额外下载 FFmpeg。

方式二：手动下载后安装

从下载页取得 Windows · x64 安装包。在资源管理器中右键压缩包，选择“全部解压”。把解压后的程序放到固定目录，例如 C:\Program Files\Visto Server，不要从 ZIP 内直接运行。

打开程序文件夹，确认里面能看到 Install-VistoServer.ps1、bin 和 web。视频组件已随 Windows 安装包提供，无需另外下载安装。

运行安装

在开始菜单搜索 Windows PowerShell，选择“以管理员身份运行”。先进入程序文件夹：

Set-Location 'C:\Program Files\Visto Server'

如果你选择了其他位置，把文件夹路径改成实际位置。然后运行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-VistoServer.ps1

安装器会创建开机启动任务。这个命令只为本次运行指定执行策略，不需要修改系统的全局设置。

打开 Visto

安装结束后，在这台电脑的浏览器打开 http://127.0.0.1:8787/，按首次设置完成配置。若页面暂时打不开，稍等片刻再刷新。

先上传一个短视频，等待生成预览并尝试播放。遇到问题见排查指南，服务管理、备份和卸载见更新与维护。
