# Visto 文档网页

- 双击 `index.html`：打开多页文档中心；请保留整个文件夹及 `assets/`。
- 双击 `Visto-用户手册.html`：单文件离线版，配图、样式、搜索均已内嵌，只需这一个文件。
- 多页版本可部署到普通静态服务器；本站不需要数据库、构建服务或外部 CDN。
- 使用全文搜索、左侧章节目录、右侧本页目录、上一章 / 下一章、图片放大、主题、复制与打印。
- 快捷键 `⌘K` / `Ctrl+K` 打开搜索，`Esc` 关闭弹窗。手机使用右上角“目录”。
- 搜索、主题与弹窗需要 JavaScript；禁用脚本后正文和导航仍可阅读。
- 打印时会去掉导航和交互控件；单文件版适合打印整本，章节页适合打印一章。
